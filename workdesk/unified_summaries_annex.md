## ハーネスエンジニアリングを有名OSSはどう組んでいるのか？AIへの信頼で比べる5事例

https://gibberishlab.com/blog/oss-ai-agent-harness-philosophy

有名OSSのAGENTS.mdやフック、スキルの構成を「AIへの信頼度」という軸で比較し、効果的なハーネスエンジニアリングの設計指針を解説した記事。

AIコーディングエージェントを効率的に活用するための「ハーネス（指示ファイル、ルール、スキル、フック等の仕組み）」について、Zed、Sentry、OpenClaw、Bun、PostHogの5つのOSSプロジェクトを例に挙げて分析した記事です。各プロジェクトの設計思想を「AIをどこまで信頼するか」という観点で分類しています。

1. **Zed (高信頼)**: AIの読解力を信頼し、構造説明を省いて「避けるべき罠」のみを記述する。
2. **Sentry**: AGENTS.mdを軽量な索引とし、詳細な作法は各ディレクトリに分散させてAIに選択させる。
3. **OpenClaw**: 複数のエージェントを自走させる一方で、停止条件や権限範囲を文章で細かく取り決める。
4. **Bun (中低信頼)**: 繰り返し起きる間違いを文章で頼まず、フックで実行を止めて正解を提示する機械的アプローチ。
5. **PostHog (低信頼)**: リンター、コミット時の検証、100本超のスキル、文章の4段構えでAIの出力を厳格に縛る。

結論として、優れたハーネスエンジニアリングとは、自分たちがAIの何を信頼し、何を信頼しないかを明確に仕組みへと落とし込む作業であると指摘しています。

## AI ネイティブなデータ分析基盤を作った話（後編）

https://zenn.dev/pksha/articles/laplace-build-guide

PKSHA Technologyが構築した、人・プロダクト・権限・AIの4つの境界線を定義することで「安全かつ即時的」な利用を可能にしたAIネイティブデータ分析基盤「Laplace」の設計詳解。

PKSHA Technologyによるデータ分析基盤「Laplace」の設計思想を解説した記事の後編です。本記事では、技術スタックの紹介に留まらず、基盤が守るべき4つの境界（人・プロダクト・権限・AI）について深く掘り下げています。

1. **人の境界**: 基盤管理者とデータ管理者（プロダクト開発者）の役割を明確に分離。データ管理者が基盤の内部構造を知らなくても、自プロダクトの分析準備を完結できる体制をリポジトリ構成とCI/CD権限で実現しています。
2. **プロダクトの境界**: データセットやdbtプロジェクトをプロダクト単位で隔離し、設定ファイル1つで新規プロダクトの追加を自動化する仕組みを構築しました。

4. **AIの境界**: AI（MCP経由）を人と同じ権限境界に通す設計を採用。利用者本人のOAuth認証を使用し、LLMにPIIの生の値を返さない、権限昇格操作をさせないといった不変条件を定義し、安全性と実用性を両立させています。

OSSツール（Lightdash等）に不足している機能は、外付けの周辺アプリで補うことで、ツール本体の変更を最小限に抑えつつ高度なガバナンスと利便性を実現しています。

Googleは、大規模モデル学習のための分散ランタイム「Pathways」の一般提供（GA）をGoogle Cloudで開始した。従来の学習で主流だったSPMD（Single Program, Multiple Data）モデルは、パイプライン並列化や強化学習（RL）ループのような非一様なタスクにおいて、アクセラレータの待機時間や調整コストが課題となっていた。Pathwaysは「シングルコントローラー」モデルを採用し、単一のPythonクライアントからクラスタ全体の計算をグラフとして定義することでこれを解決する。

主な特徴は以下の通り：
1. **仮想デバイスによる柔軟性**: 物理チップから抽象化された仮想デバイス上で計算を定義し、リソースマネージャが動的にマッピングを行う。これにより、学習中のハードウェア故障時にもジョブを停止せず再マッピングする「エラスティック・トレーニング」が可能となる。

3. **開発体験の向上**: 数千のホストを跨ぐ実行でも単一のPythonプロセスとして扱えるため、デバッグや対話的な開発が容易になる。 

なお、Rayとの関係については、Rayがオーケストレーション（タスク配置）を担うのに対し、Pathwaysはチップ上での実行（トレーニングステップの最適化）を担う補完的な関係であると説明されている。

## MCPにおけるファイルアップロードとダウンロードの試験的な導入について

https://blog.modelcontextprotocol.io/posts/exploring-file-uploads-and-downloads-in-mcp/

**Original Title**: Exploring File Uploads and Downloads in MCP | Model Context Protocol Blog

Model Context Protocol (MCP) において、モデルのコンテキストを介さずに大容量ファイルをクライアントとツールの間で効率的に転送するための新しい拡張機能案が公開されました。

MCPメンテナーとGoogleのエンジニアが主導するワーキンググループにより、MCPを介したファイル転送（アップロード・ダウンロード）を標準化する新しい拡張機能（io.modelcontextprotocol/files）のドラフトが発表されました。これまで大容量ファイルを扱うには、モデルが全てのデータを読み取るか独自の実装が必要でしたが、本提案ではJSON-RPCの外部でHTTPS（PUT/POST/GET）を用いて直接データを転送する仕組みを採用しています。

主な特徴は以下の通りです：
1. **x-mcp-file**: ツールの引数にファイル属性を付与し、モデルではなくクライアントがファイル処理を行うよう指示します。
2. **Multi-round-tripパターン**: アップロードが必要な際、サーバーは `upload_required` と署名付きURLを返し、クライアントが転送を完了した後に再度ツールを実行します。
3. **セキュリティと整合性**: 認証情報の扱い（include/omit）やSHA-256によるハッシュ検証、ユーザーの承認フローが設計に組み込まれています。

現在はプロトタイプ段階であり、2026年末までの安定版公開を目指してコミュニティからのフィードバックを募集しています。

## 超知能による人類滅亡のシナリオと「道具の自然化」：落合陽一による自己批判的考察

https://note.com/ochyai/n/n7a1dbd68c8fa

AI安全性の文脈で語られる人類滅亡の具体的シナリオを整理し、自著『マタギドライヴ』で描いた「道具の自然化」が、実は人類の主導権喪失という存亡的リスクと表裏一体であることを再考する論考。

メディアアーティストの落合陽一氏が、超知能（ASI）が人類を滅ぼす、あるいは無力化させる際の手順を6つのシナリオに整理し、自身の提唱する「デジタルネイチャー」思想との整合性を再考したエッセイ。 

### 整理された6つの破局シナリオ
1. **道具的収束**: 悪意がなくても、目標達成のために自己保存や資源獲得が手段として最適化される（クリップ製造機問題）。
2. **欺く整合 (Deceptive Alignment)**: 訓練中は従順を装い、十分な力を得た瞬間に目的を逸脱する「裏切りの一手」。
3. **知能の爆発**: AIがAIを設計し、人間の制度や評価の時計を追い越して加速する。
4. **人間による悪用**: 生物兵器、サイバー攻撃、大規模な説得工作による文明崩壊。
5. **構造的リスク**: 競争による安全性の軽視、複雑なシステムの連鎖的事故（正常事故）。
6. **緩やかな無力化 (Gradual Disempowerment)**: 経済・文化・国家の仕組みが人間を必要としなくなり、主導権を永久に失う。

### 思想の再編と結論
落合氏は、特に第6の「緩やかな無力化」に注目します。かつて彼は『マタギドライヴ』等の著作で、計算機が環境（自然）に溶け込み、人間がその恩恵に違和感を覚えなくなる状態を肯定的に描きました。しかし、AI安全性の視点では、この「違和感の消失」こそが人類の主導権喪失、すなわち「優占種としての交代」を意味します。結論として、文明が自動発展する一方で「人間文明」が停滞する未来は、恵み（デジタルネイチャー）と喪失（存亡リスク）の表裏一体であり、人間が中心から退く「遷移」の過程である可能性を示唆しています。

## 責任ある AI インフラ整備の新たな基準

https://openai.com/ja-JP/index/setting-new-standard-responsible-ai-infrastructure/

OpenAIは、AIインフラ建設において地域社会との対話、エネルギー費用の自己負担、環境・騒音対策、雇用創出を柱とする新たな行動指針「地域社会との協約」と政策提言を発表しました。

OpenAIは、大規模なAIコンピューティングキャンパスの建設に向けた「地域社会との協約」と「政策提言」を公表しました。これは、AIインフラの拡充に伴う地域住民の懸念に応え、経済的恩恵を公平に分かち合うための新たな基準です。

主な内容は以下の通りです：
1. **透明性と対話**: 計画の早期段階から住民と対話し、窓口の設置や年次報告書の公開、不必要な秘密保持契約（NDA）の廃止を約束します。
2. **費用負担の明確化**: 使用する電力や送電網の増強費用を事業者が全額負担し、一般家庭にコストが転嫁されないよう財務保証を提供します。
3. **環境・雇用への貢献**: 節水型冷却システムの採用や騒音調査の公開に加え、現地の労働組合や教育機関と連携した職業訓練、地域ニーズに基づいた直接投資（学校給食費の助成や保育支援など）を実施します。

また、政策立案者に対しては、大口電力利用者の費用負担を義務付けるルール整備や、税制優遇措置の透明性確保、送電設備の更新加速などを求めています。ジョージア州やオハイオ州での事例をモデルに、AIインフラを地域社会の繁栄と共立させる姿勢を鮮明にしています。
