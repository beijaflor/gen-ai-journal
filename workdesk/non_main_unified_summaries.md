## エージェント相互運用規格の到来：AI開発の焦点は能力からインターフェースへ

https://www.oreilly.com/radar/the-interfaces-are-arriving/

AIエージェント開発は、これまでモデルのプランニング能力やツール利用といった「能力」に注力してきましたが、現在は「インターフェースの標準化」という大きな転換点を迎えています。Anthropicが寄贈した「Model Context Protocol (MCP)」やGoogle主導の「Agent2Agent (A2A)」が、Linux Foundation傘下の「Agentic AI Foundation」で管理されるようになり、ベンダーを超えた相互運用性が確保されつつあります。

- **Model Context Protocol (MCP)**: AIアプリケーションとツールやコンテキスト間の接続を標準化します。LSP（Language Server Protocol）に倣い、一度の実装で複数のIDEやチャットアプリに対応可能にします。

この標準化により、統合（インテグレーション）が特定のモデルに依存しない「再利用可能な資産」となります。また、OAuth 2.1やPKCEなどの既存のセキュリティ規格を適用しやすくなるメリットもあります。一方で、プロトコルは現在も急速に進化しており（MCPは2年で5回改訂）、開発者は今後の仕様変更やセキュリティ境界の設計に注視し続ける必要があります。
